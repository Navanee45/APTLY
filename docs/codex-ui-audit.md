# APTLY UI & Product Engineering Audit

**Audit date:** 2026-08-17  
**Scope:** Existing repository only. This document records observed code and test evidence; it does not claim live Supabase, Gemini, WhisperX, TTS, or browser-device validation.

## Architecture observed

| Area | Current implementation |
| --- | --- |
| Web | Next.js 16 App Router, React 19, TypeScript, Tailwind 4, Supabase JS/SSR, React Query. |
| API | FastAPI with async SQLAlchemy, migrations, structured error middleware, provider abstractions, and endpoints for interviews, profiles, progress, documents, storage, realtime, and health. |
| AI/media | Gemini and WhisperX providers exist alongside explicit mock providers; MediaRecorder capture, browser audio level monitoring, MediaPipe client hook, transcript timestamps, and speech metrics are present. |

| 3D | No Three.js, React Three Fiber, or Drei dependency/component was found. |

## Evidence-based implementation order

1. **Security and data isolation:** replace the JWT fallback, add ownership checks to every interview mutation and media endpoint, user-prefix storage keys, and validate Supabase RLS with two users.
2. **Reliability:** create an explicit interview/recording transition machine; harden MediaRecorder finalization, uploads, interruptions, and playback.
3. **Truthful coaching:** remove UI fallbacks that look like real scores/coaching; persist multimodal evidence and build report/habit/drill views exclusively from it.
4. **Foundation:** restore lint, improve tests, standardize scoring version, typed API errors, and route guards.
5. **Product UX:** introduce semantic design tokens, responsive application shell, complete reports/practice/settings/demo routes, then add accessible visual analytics.
6. **Purposeful 3D:** after the above is stable, add lazy, reduced-motion-aware R3F AI/progress state components with 2D equivalents.

## Limitations of this audit

- No credentials, live Supabase project, Gemini key, WhisperX runtime, TTS provider, camera, microphone, or browser session were supplied; no live integration claim is made.
- Static inspection can identify missing controls but cannot certify that an external RLS policy is deployed or that device/media behavior works across the requested browser matrix.
